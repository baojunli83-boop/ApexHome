# Apex Home Company Website

Single-page bilingual (English / Chinese) website for Seattle Apex Home Construction, LLC.

## Files
- index.html
- styles.css
- script.js

## GitHub Pages
Upload these files to the root of your GitHub repository, commit, and push to `main`.
If GitHub Pages is already configured for `main` / root, the site will redeploy automatically.

## Notes
Project facts and company details in this version are based on the company introduction / construction estimate supplied by the owner.
The project artwork is intentionally abstract placeholder artwork. Replace it later with actual project photography/renderings.
