# Apex Home Company Website V2

Bilingual single-page website for Seattle Apex Home Construction, LLC.

## Improvements in V2
- Real 3803 Bellevue completed-project photography
- 10435 Bellevue architectural renderings
- 17023 Renton / Victoria Garden architectural renderings
- Clickable lightbox galleries with previous/next controls
- English / Chinese toggle
- Responsive desktop and mobile layout
- Hero image uses the completed 3803 Bellevue residence

## Project facts
Website text is based on the company introduction / construction estimate supplied by the owner.
10435 and 17023 images are labeled as architectural renderings.
3803 is presented as a completed residence.

## Deploy
Upload all files and the `assets` folder to the root of your GitHub repository.
Commit and push to `main`. Existing GitHub Pages deployment from `main` / root will update automatically.
